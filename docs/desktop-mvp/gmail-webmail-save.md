# #357 Gmail 网页保存

## 状态与范围

实现基于 #333 已有的插件侧栏、Native Messaging 分块传输、原件／摘录入档和去重。只新增 Gmail 页面适配与临时目标重核，不改桌面协议，不增加扩展权限，也不接入 Google OAuth 或 Gmail API 自动收信。

**2026-10-30：代码和合成 DOM 测试已实现，用户尚在准备真实 Gmail 测试页面。当前页面结构、普通阅读页原件入口、原始邮件页下载，以及个人／Workspace／Googlemail／Chrome／Edge 均不得标为真实账号已验证。** 未满足真实验收前不关闭 #357，不把测试返回的 MIME 视为 Gmail 线上下载成功。

## 使用边界

- 入口仅依据活动标签页 URL 启用，支持 HTTPS 的 `mail.google.com`、`mail.googlemail.com` 下桌面版 `/mail/u/<数字>/` 路由；手机页、登录页、其他域名、仿冒后缀不启用。不在打开侧栏或刷新标签信息时读取邮件。
- 普通阅读页识别一个可见阅读区域与一个展开的单封卡片，分别读取该卡片的发件人、显示时间、正文及所属会话标题。折叠邮件、隐藏旧阅读窗格、正文伪造的卡片或工具栏不参与目标识别。
- 多封同时展开时要求用户只展开要保存的那封，不猜最新邮件、不自动读取整段会话，也不自动收起或展开邮件。未知结构、账号标识缺失、邮件编号冲突等情况拒绝猜测，提示刷新或手动导入。
- 点击时从 Gmail 页面的账号控件取得账号邮箱，用于本次请求前后核对，不发给桌面、日志或产品服务器。页面邮件编号只作为瞬时来源定位，不伪造成 RFC Message-ID。

## 原件入口

当前适配只使用 Gmail 自身页面已经提供的链接，不点击页面菜单、不遍历 Gmail 私有 JavaScript 数据、不拼接隐藏接口或导出 Cookie。

1. **普通阅读页**：只接受原生邮件头工具区或菜单中已暴露、与当前单封邮件编号及账号路径相符的原文链接。未暴露可校验链接时提供网页摘录确认，同时指引用户在该封邮件菜单中打开“显示原始邮件”。不承诺普通阅读页任意版本都能一键取得原件。
2. **Gmail 原始邮件页**：用户自行打开“显示原始邮件”页后，可在插件侧栏保存；使用该页实际提供的下载原始邮件链接，核对当前页与链接的单封标识、同源和账号路径。
3. 只允许限定只读路径、参数及整封邮件模式，拒绝其他邮件编号、其他账号路径、跨源链接、动作参数、重复参数和单附件链接。会话参数只在页面请求中使用，不输出到桌面或日志。
4. 使用 #333 的流式 25 MiB 上限、20 秒超时及邮件格式校验。HTML 原文预览、登录页和错误页不冒充 `.eml`；不从 HTML／textarea 重建 MIME。
5. 普通阅读页取不到原件时，用户再次点击“保存网页摘录”才入档，明确缺少原件及附件。原始邮件页下载失败则提示手动下载导入，不把原文展示页整体保存成正文摘录。

原文入口是本轮真实验收的重点，后续依据观察到的页面结构修复适配；不能为了通过模拟测试而声称所有菜单、语言或 Workspace 策略都已支持。

## 切换与临时状态

- 捕获时固定页面、账号控件、单封标识、标题、正文、DOM 节点与路由；下载完成后再次核对。
- 页面内只保留一份临时目标快照，给侧栏返回随机的一次性标识，标识不含账号、正文、会话 URL 或邮箱内部邮件编号。
- 原件传给桌面前以及用户确认摘录时，侧栏向当前顶层内容脚本核验临时标识，再确认活动标签页仍一致。相同 URL 下换账号、换邮件或重新加载页面也不能复用旧标识。
- 核验会消费标识；取消摘录发送只释放快照的消息，不重新读取邮件。新捕获覆盖旧快照；hash 导航和 pagehide 释放。目标改变时丢弃提案，要求重新保存。
- 桌面沿用既有 archive ID／restore epoch、分块摘要与完成回执；只有实际持久化成功才显示保存完成。原件幂等去重；摘录保持独立来源，不承诺与以后原件自动合并。
