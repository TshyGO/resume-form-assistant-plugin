# 网申快填使用指南

[返回项目首页](../README.md) · [下载与安装](../README.md#下载与安装) · [隐私政策](privacy-policy.md)

本页补充首次使用之后的操作细节、旧数据迁移与常见问题。新用户先按首页的「快速开始」安装桌面应用和浏览器扩展。

## 反馈问题与错误报告

插件侧栏「填写」页（一键填写和填写诊断下方）提供“手动反馈问题”，默认折叠，点“展开”填写。填写问题描述，可勾选最近一次填写诊断，点击“预览将发送的内容”，核对不含个人信息、简历或密钥后点击“确认发送”。草稿、发送中或发送失败时都可以点“收起”，收起不会清除草稿，也不会取消正在进行的发送。发送成功后草稿和预览清空并自动收起，只显示反馈编号；下次展开是新的草稿，需要重新预览确认。失败不会自动重试，草稿保留，可展开修改后重新预览发送，两次发送至少间隔 60 秒。浏览器后台休眠后预览可能失效，界面会提示重新预览确认。

“自动错误报告”与“手动反馈问题”互相独立。自动错误报告默认开启：插件检测到自身异常或字段没填上时，自动发送脱敏诊断，帮助定位问题、改进填写兼容性。首次打开侧栏时，一键填写按钮下方显示说明公告，可点“知道了”只收起公告，或点“关闭自动错误报告”立即关闭；首次打开状态页时，说明直接在“自动错误报告”框内展开，点“知道了”收起。未确认公告也可能自动发送。以后开启或关闭，在「插件状态」页勾选或取消勾选“开启自动错误报告”；需要重看说明时，在该框内点“查看完整说明”展开、点“收起说明”收起。关闭会删除随机安装标识，不影响填写和手动反馈。升级保留已明确关闭的选择。

桌面端的自动错误报告也默认开启，首次打开界面时显示说明公告，可点“知道了”收起，或点“关闭自动上报”立即关闭；桌面开关与插件独立，可随时在“设置 → 隐私”调整。该页也有“反馈问题”，自动附上版本和系统，同样先预览再确认发送。

报告通过 Cloudflare 暂存（最长 90 天），Muse 脱敏后整理为 GitHub issue；报告可能公开，出错网站域名保留用于复现。详情见[隐私政策](privacy-policy.md)。

## 连接与安装方式

优先从 [Chrome 商店](https://chromewebstore.google.com/detail/diagjmploldedipjdenmecmjokckelkl)安装扩展。商店审核及更新分发可能晚于 GitHub；商店不可用、版本落后于发布页配套插件或提示不兼容时，使用[正式版下载页](https://19991107.xyz/tools/wangshen-kuaitian/download/)中的插件 ZIP，操作见[手动安装](../README.md#手动安装扩展)。

桌面和扩展独立发版，版本号不要求相同。使用发布说明列出的配套版本，不要单靠数字是否一致判断兼容性。

桌面至少打开一次，再重启浏览器，让浏览器读取连接注册。点击工具栏图标打开侧边栏后：

- 显示「这个浏览器还没和桌面配对」：复制扩展 ID，在桌面「设置 → 浏览器连接」中按提示配对。
- 显示「需要先安装桌面程序」：确认桌面已安装、能正常启动，再检查连接注册。
- 显示正常的模板与字段：已经连接。

只有界面提示需要配对时才手动处理扩展 ID。关闭桌面窗口会收起到托盘或菜单栏；主动退出后，插件后台查询和同步不会重新启动桌面，重启浏览器也不会。双击桌面程序或点击插件的「打开桌面」后恢复连接，待同步数据继续保留。

插件状态页可从侧边栏底部的「插件状态」进入，或右键工具栏图标选择「选项」。

## AI 配置

进入桌面「设置 → AI 设置」，添加服务商并设为「当前使用」。

| 设置 | 填什么 |
| --- | --- |
| 接口地址 | 服务商提供的 OpenAI Chat Completions 兼容接口地址 |
| API Key | 该服务商发给你的密钥 |
| 模型 | 点击「获取模型」选择，并确认账号有权限使用 |

可以添加多个服务商，切换当前使用的配置。软件不赠送模型额度，也不代办 API 账号。请尽量使用 HTTPS；HTTP 会明文传输请求。

预设里有 OpenCode Go。它只能用走 Chat Completions 的模型（OpenCode 文档模型表里 Endpoint 是 chat/completions 的那些），Grok、GPT 等走其他接口的模型用不了。

API Key 保存在 macOS 钥匙串或 Windows 凭据管理器中，不写进扩展，不进入桌面备份。恢复备份后，需要检查并按提示重新配置密钥。

不配置 AI，仍可导入 Excel 模板、点击字段辅助填写，并使用本地岗位管理。AI 简历解析、AI 填写、岗位识别中的 AI 回退和通知 AI 整理需要可用的服务商配置。

## 简历与我的信息

### 用 AI 解析简历

在桌面「简历」页选择 AI 解析，导入 PDF、DOCX 或 TXT。发送前会显示服务商和字数，确认后再发送。

PDF、DOCX 会先在本机提取文字，随后把文字发送给配置的 AI 服务商。扫描件、加密 PDF 等无法提取文字时，请改用可提取文字的 PDF、DOCX 或 TXT。

解析完成会生成新模板并设为当前。AI 可能遗漏或理解错字段，请在模板里核对，也可导出 Excel 修改后再导入。

### Excel 与 CSV 格式

前三列按顺序为「一级分类」「字段名」「值」，第一行为表头。

| 一级分类 | 字段名 | 值 |
| --- | --- | --- |
| 基本信息 | 姓名 | 张三 |
| 基本信息 | 邮箱 | example@example.com |
| 教育背景 | 学校 | 示例大学 |
| 教育背景 | 专业 | 材料科学与工程 |
| 教育背景 | 学历 | 硕士 |
| 教育背景 | 入学时间 | 2023-09 |
| 教育背景 | 毕业时间 | 2026-06 |
| 实习经历 | 公司 | 示例公司 |
| 实习经历 | 岗位 | 研发实习生 |

保存为 `.xlsx` 或 UTF-8 编码的 `.csv`，在桌面「简历」页导入。Excel 只读取第一个工作表。「字段名」不能留空，学校、专业、学历等信息建议拆开填写。

导入采用整份校验：有一行缺少字段名，整个文件都不会生效，当前模板保持不变。提示会列出错误行号；错误很多时，请检查第二列是否因插入、删除列而错位。

### 多套模板与补充资料

最多可保存 25 套模板，例如研发岗、产品岗、英文简历等。网页填写前在侧边栏切换「当前模板」，选择会同步到桌面。

「我的信息」适合补充籍贯、户口、家庭成员等简历里通常没有的网申字段。

桌面正在编辑时，若扩展新增了补充字段，当前草稿会保留。选择「稍后处理」可以继续编辑；「放弃未保存修改并重新读取」需要再次确认。当前不会自动合并本地草稿和外部修改。

## 自动填写与手动补填

在当前网申表单中点击「一键 AI 填写」，完成后检查提示和高亮字段。再次填写时，若本次匹配的字段已有内容，会在 AI 匹配完成后、写入前询问是否允许重新填写。

取消覆盖确认，本次不写入字段；之前发出的 AI 请求不会撤回。网站提交前仍需自行核对。

手动补填时，先点击网页中没填好的文本输入框，再点击侧边栏字段。空输入框可以直接点击字段填写；已有内容时，字段右侧提供：

| 操作 | 行为 |
| --- | --- |
| 添加 | 在上次点击的光标位置插入该字段，切到侧边栏后仍会记住位置 |
| 替换 | 用该字段替换整个输入框 |
| 删除 | 删除这个字段对应的内容，保留其他内容 |

输入框里已包含的字段会加深显示；不会改变内容的操作会变灰。「简历字段」页支持搜索全部字段。

密码、验证码、文件上传和非文本控件不会启用这些文本操作按钮。普通输入框、文本框、下拉框、单选框以及部分日期和级联控件已有适配，高度定制的页面仍需手动处理。

## 岗位保存与填写留档

### 保存岗位和确认投递

在侧边栏「填写」页点击「保存岗位到桌面端」，核对公司和岗位后确认保存。来源网址只读且已脱敏；需要 AI 识别时会说明发送的页面文字数量，并可取消。疑似重复的岗位由你选择关联已有申请或另存为新申请。

「确认已投递」会查找当前公司在桌面中的申请，让你选择对应岗位，即使只有一条也不会自动替你选。没有候选或无法识别公司时，先保存岗位，再回来选择。

**该操作仅更新桌面中的阶段，不会提交招聘网站的申请。**

### 填写记录与简历快照

完成「一键 AI 填写」或「AI 辅助新增条目」后，可选择把本次填写留档。留档保存结果摘要和计数，例如字段数量、耗时和所用模板，不记录网页输入框中的实际填写值。

默认可附带本次使用的简历模板快照，也可以取消勾选。快照在填写开始时冻结，后续编辑模板不会改变它。它只能说明本次使用了哪份资料，不能证明网站最终收到了什么。

留档需要选择关联申请；没有候选时，可先保存岗位再「重新查找」，也可选择稍后在待同步中处理。取消留档不建立记录，也不暂存该次快照。

只有桌面确认持久化后才显示「已留档到桌面」。记入待同步时，会明确提示尚未留档到桌面。

### 待同步记录

侧边栏「填写」页的「待同步 N 条」支持选择留档对应申请、完成岗位保存、重试、删除记录和丢弃过期快照。关闭招聘网页后，队列仍可在侧边栏中查看。

请区分保存结果：

- 未安装或未配对：这次没有保存岗位，也不进入待同步；先安装并完成连接，再重新保存。
- 曾经配对、桌面暂时不可用或协议不兼容：允许记入待同步的操作会明确显示尚未保存到桌面，恢复连接后按提示处理。
- 没有回包（结果未知）：让你到桌面或待同步列表核对，不声称已保存、已排队或已确认。

简历字段和 AI 填写仍依赖桌面连接。快照暂存于扩展自己的 IndexedDB，传输完成后才清理副本。恢复桌面备份后，按界面提示核对队列，不要把恢复前的待同步内容误当成已写入新档案。

## 招聘材料与待办

「证据收件箱」支持导入 `.eml` 邮件、PNG/JPEG 截图、PDF，或粘贴一段文本。文件被复制到本地档案中，移动或删除外部原文件不会影响已导入的副本。

导入后由你确认关联和分类，不会因导入本身自动改变申请阶段。同一家公司多条申请需要自己选择，不会自动归并。AI 整理会在发送前展示将要发送的内容，处理结果仍需核对。

当前不支持直连邮箱、Outlook `.msg` 或虚拟拖拽对象；可另存为 `.eml` 或粘贴正文。单个文件上限 25 MiB，一次最多 20 个。邮件以安全纯文本预览；PDF 可用系统程序打开本地副本。

「待办」可关联申请，设置无到期日、仅日期或具体时间。系统提醒受权限、系统状态与平台能力影响，应用中会显示当前能力与运行条件。关闭窗口仍会驻留；主动退出会暂停提醒。重要测评和面试请保留其他提醒方式。

在「设置 → 数据与备份」导出备份或预览恢复内容。备份不包含 API Key；恢复前核对范围，按界面提示确认。更详细的数据范围见[数据与隐私说明](desktop-mvp/data-privacy.md)。

## AI 填写耗时与诊断

按钮会显示扫描、AI 匹配计时和填写阶段。「填写诊断」保留错误类别和失败阶段（扫描、匹配或填写）、是否判断为网申填写页、输入框漏斗（页面共有、可见可填、进入匹配、匹配、填入）和每一步丢掉的原因，以及扫描、匹配往返、API、填写与总耗时、提示词字节数，可复制反馈。没跑的阶段显示“未执行”，跑了但没拿到结果的显示“未取得”，AI 没被调用显示“未调用”，都不会显示成零耗时。在不是网申填写页的页面点一键填写，侧栏会提示先打开申请表页面，这种情况不自动上报。

等待超过 90 秒会显示慢响应提醒，不会因此自动取消。可点击「取消 AI 等待（保留本地匹配）」主动终止等待，但这不能保证上游停止计算或计费。

AI 失败或主动取消后，会使用已验证的本地匹配结果，并明确提示部分完成；不会自动重试或更改接口设置。浏览器退出、扩展重载、网络或上游服务异常仍可能中断请求。

诊断摘要包含版本、计数、字节数、耗时和标准错误类别，另附网站域名（不含路径和参数）、页面结构线索（内嵌框架、自定义控件、「编辑」按钮等的数量），以及没填上字段的字段名和控件结构（标签、类型、组件库）。字段名最多保留 16 个字；含 @、网址、长串数字，与要填写的值重叠，或包含简历里的内容时隐藏。诊断不包含字段值、接口地址、API Key、简历正文或上游错误原文，只在本机显示；点「复制诊断」后由你决定发给谁。截图前仍需检查周围网页和模板中的个人信息。

## AI 辅助新增条目

这是可选实验功能，不改变普通「一键 AI 填写」的使用方式。

网页只显示一条论文或经历时，可点击「AI 辅助新增条目」。插件先识别候选新增按钮，交给 AI 规划；侧边栏展示计划后，由你点「确认新增」，再逐次新增并填写新分组中的空文本字段。

规划阶段只发送候选新增按钮的编号、类型和条目数量，不发送简历正文。后续匹配新字段时，会使用相关简历内容。通常需要规划与匹配两次模型调用。

支持明确标注的论文、教育经历或教育背景、工作经历、项目经历。需要结构清晰的分组和唯一新增按钮，每次最多新增 5 条；结构不明确时请手动操作。没有正式工作经历时，可用实习经历推导通用工作分组的条目数；两类同时存在时不会自动混合。

此辅助模式只填相关分组的空文本框和文本域，复杂下拉框、日期等控件不纳入该模式。写入后会短暂等待并读回确认，但这不能证明网站服务器已保存。

预览期间切换标签页、网页地址或模板变化、分组变化，会使计划失效，需要重新预览。执行中遇到按钮变化、数量异常、网页重建字段，或 2.5 秒内未确认新增，会停止且不重复点击。

可在规划和新增期间停止。停止或失败时，已经新增的空条目不会自动删除，界面会显示实际新增数量；网站自身的新增操作可能触发保存，确认前请留意。

## 旧版数据迁移

0.4.0 及更早的扩展将模板、「我的信息」和 AI 配置保存在浏览器中。升级到 0.4.1 的桌面协作方式时：

1. 安装桌面应用并连接浏览器。
2. 扩展发送旧数据，在桌面「简历」页核对待导入内容。
3. 点击「导入到桌面」。桌面已有「我的信息」时，自行选择保留哪份。
4. 导入成功后，扩展清理已经完成迁移的旧数据。

**确认之前不会删除旧数据。** 选择「不导入」后，仍可在插件状态页重新发送。不要在迁移或取回完成前卸载旧扩展、删除浏览器 Profile 或清除存储。

密码、验证码类的「我的信息」字段不会迁移。超过 24 KB 或超出 25 套数量上限的模板不会迁移，可在插件状态页下载 CSV，再到桌面导入。

若系统凭据库暂时不可用等原因导致 AI 配置导入失败，简历仍可迁移，未迁移的旧 API Key 会留在扩展。可在插件状态页取回，到桌面配置后再删除旧副本。

原 Resume Pro Desktop 测试版更名升级请另看[安装与升级说明](desktop-mvp/install-and-update.md#52-从-resume-pro-desktop-测试版升级到网申快填)。

## 常见问题

### 点击图标没有打开侧边栏

确认扩展已启用，浏览器为支持的版本，并刷新已打开的网页。`chrome://extensions`、`chrome://settings`、`edge://extensions` 等浏览器内部页面不能注入普通扩展内容，请在普通招聘网页测试。侧边栏左右位置由浏览器设置决定。

### 连不上桌面或提示没配置 AI

确认桌面已安装且能启动；按侧边栏的未配对、缺少桌面或版本提示处理。商店版本尚未同步时，可使用发布页配套 ZIP。连接正常后，在桌面「设置 → AI 设置」确认服务商已设为「当前使用」，地址、模型和 Key 已填写。

### AI 接口请求失败

检查 Key 是否失效、余额和限流、模型名称与权限、接口地址，以及接口是否兼容 OpenAI Chat Completions。侧边栏诊断会区分认证、限流、超时、网络等问题。

慢响应可能来自模型、转发服务、网络或输入量，不能仅凭等待时间断定某一方故障。不要在反馈中公开 Key 或未脱敏的请求正文。

### Excel 导入失败

确认文件为 `.xlsx` 或 UTF-8 `.csv`，第一行为表头，前三列依次为「一级分类 / 字段名 / 值」，每行第二列都有字段名。按提示行号修正后重新导入。

### 提示“当前页面没有可填写的表单字段”

猎聘等网站的在线简历默认是查看状态，要先点网页上的「编辑」，等输入框出现后再一键填写。这类网站通常每块单独编辑、单独保存，需要一块一块填。插件检测到「编辑」按钮时会直接这样提示；页面处在查看状态时，「已填写 0 个字段」或「简历里没有能对应这些网页字段的资料」后面也可能跟着同样的「先点编辑」提示。表单在内嵌框架里或用了暂不支持的控件时，请按下一节的方式反馈。

### 字段填错或网站显示仍未填写

手动核对并按网站要求完成交互，尤其留意日期、学历、证件类型、地区、级联下拉框与多段经历。网页控件显示有文字不保证网站已经接受或保存该值。

兼容性反馈请提供网站域名、卡在哪一步、打码后的截图，以及展开侧栏「填写诊断」、点「复制诊断」得到的文字。可复现问题用 [GitHub Issues](https://github.com/TshyGO/resume-form-assistant-plugin/issues/new/choose) 的「网站填不上 / 填错」模板提交，也可以先到[QQ 交流群](../README.md#-qq-交流群)交流。
