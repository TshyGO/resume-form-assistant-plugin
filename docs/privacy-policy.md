# Resume Pro 隐私政策

最后更新：2026-09-21

Resume Pro 是一个求职网申的填写辅助工具，由浏览器扩展和桌面程序两部分组成。
这份政策说明它**收集什么、不收集什么、数据去了哪里**。

## 一句话

**我们没有服务器，也不接收你的任何数据。** 简历、申请记录、附件全部留在你自己的电脑上；
只有你主动使用 AI 功能时，相关内容才会发给**你自己配置的**那家 AI 服务商。

## 数据存在哪

| 数据 | 位置 |
| --- | --- |
| 简历模板、字段设置、AI 配置（扩展侧） | 浏览器的 `chrome.storage.local`，只在这台机器上 |
| 申请记录、回复证据、附件、待办、备份（桌面侧） | Windows `%LOCALAPPDATA%\ResumePro`，macOS `~/Library/Application Support/ResumePro` |
| 桌面的 AI API Key | Windows 凭据管理器 / macOS 钥匙串。不进档案、不进备份、不进日志 |

扩展侧的 AI Key 和扩展现有配置一起存在浏览器的本地存储里（本机磁盘明文；这是浏览器扩展的常规存储方式）。桌面侧的 Key 单独存系统凭据库，两边不互相复制。

卸载扩展会清掉扩展侧的存储；卸载桌面程序**默认保留**上面那个档案目录，要删得在卸载器里单独确认一次。

## 会发到外面的东西

以下 AI 功能会把用户内容发到你自行配置的接口，均由你主动触发：

1. **扩展的「AI 填写」及「AI 辅助新增条目」**：把当前表单的字段说明和相关的简历片段，发给你在设置里填的那个 OpenAI 兼容接口；辅助新增条目时会发送页面中候选新增按钮的说明及条目数量，以生成供你预览的新增方案。
2. **扩展的「AI 解析简历」**：选择 PDF、DOCX 或 TXT 简历并点击解析后，扩展先在本机读取文件，再把提取出的整份简历文字发送到你配置的 AI 接口，以生成结构化模板。这些文字可能包含姓名、联系方式、教育和工作经历等信息；原始文件本身不会随这个请求上传。
3. **桌面的「AI 整理」**：把你导入的那封通知的正文，和最多 8 条候选申请的**公司名、岗位名、当前阶段**，发给你在桌面设置里填的那个接口。发送前会把要发的内容摆给你看，点了「发送」才发。

这些功能都有同一件事要说清楚：**接口是你自己配的，数据会到那家服务商手里，他们可能留存。** 我们既不代理、也看不到这些请求。请求使用你配置的 API Key 向该接口认证。不配置 AI 时，仍可导入 Excel 模板、手动填写和使用本地岗位管理；AI 填写、AI 简历解析和 AI 整理不可用。

桌面程序还会在你允许的情况下去 GitHub 查一次「有没有新版本」。这个请求不带账号标识，但和任何网络请求一样会让服务器看到常规的 IP / User-Agent 元数据；它只查版本，可以在设置里关掉。

除你主动触发的 AI 功能所需的请求外，扩展不会把页面内容、填写内容或浏览记录发给第三方。

## 不会发生的事

- 不上传你的简历、申请记录、附件到我们这里——我们没有「这里」。
- 不做用户画像、不做行为分析、不埋点、不接广告或第三方统计。
- 内容脚本会在所有网站注入，用来在本地判断当前页是不是网申表单；判断只在你的浏览器里做，不上传页面内容。只有你主动使用填写功能时，才会读写当前页的表单字段。
- 扩展查询标签页 URL 来查找、复用并聚焦已经打开的 Resume Pro 管理页，避免重复开页；不通过 `tabs` 读取其它标签页正文，也不采集浏览历史。
- 不把浏览器扩展里的 AI Key 复制给桌面程序，反之亦然。两边是两条独立的凭据。

## 权限为什么要这些

| 权限 | 用来做什么 |
| --- | --- |
| `<all_urls>` 的 host 权限与内容脚本 | 网申页面遍布各家公司自己的域名，事先列不出来。内容脚本会在所有网站注入并在本地判断当前页是否为表单；只有你主动使用填写功能时才读写当前页字段 |
| `tabs` | 查询标签页 URL 以查找、复用并聚焦本扩展管理页，不通过此权限读取其它标签页正文 |
| `scripting` / `activeTab` | 按你的点击把填写逻辑注入当前页面 |
| `storage` | 存简历模板和设置 |
| `nativeMessaging` | 和桌面程序通信。host 清单里只写了本扩展的 ID，别的扩展启动不了它 |
| `offscreen` | 在离屏文档中运行随包提供的 Worker，处理用户主动触发的 AI 填写、AI 辅助新增条目和 AI 简历解析请求，避免长请求受 service worker 生命周期影响；简历文件先由扩展管理页在本机读取 |
| `alarms` | 安排与桌面程序离线补传的重试 |

## 联系方式

有问题或要求删除什么，可以在
[GitHub Issues](https://github.com/TshyGO/resume-form-assistant-plugin/issues) 上提。
不过说明白一点：**我们手里没有你的数据可删**——所有东西都在你自己的电脑上，删除它就是删你本机的文件。
