# Resume Pro 隐私政策

最后更新：2026-09-25（0.4.1：简历与 AI 设置统一由桌面程序管理）

Resume Pro 是一个求职网申的填写辅助工具，由浏览器扩展和桌面程序两部分组成。
这份政策说明它**收集什么、不收集什么、数据去了哪里**。

## 一句话

**我们没有服务器，也不接收你的任何数据。** 简历、申请记录、附件全部留在你自己的电脑上；
只有你主动使用 AI 功能时，相关内容才会发给**你自己配置的**那家 AI 服务商。

## 数据存在哪

| 数据 | 位置 |
| --- | --- |
| 简历模板、「我的信息」、申请记录、回复证据、附件、待办、备份 | 桌面程序档案：Windows `%LOCALAPPDATA%\ResumePro`，macOS `~/Library/Application Support/ResumePro` |
| AI 服务商设置（地址、模型） | 桌面程序档案目录下的设置文件，不含 Key |
| AI API Key | Windows 凭据管理器 / macOS 钥匙串。不进档案、不进备份、不进日志 |
| 扩展侧 | 浏览器的 `chrome.storage.local`：侧栏界面状态、与桌面的待同步队列、旧数据迁移状态。迁移完成后不存简历、不存 Key；只有没能迁过去的部分（见下段）暂留，直到你取回或删除 |

从 0.4.0 升级时，扩展里旧版留下的模板、「我的信息」和 AI 配置（含 Key）会在你于桌面确认后迁入桌面，随后从扩展里删除；迁移只经本机 Native Messaging，不经过网络。没能迁移的部分（桌面拒收的模板、桌面没导入的 Key）留在扩展里，你可以在扩展状态页取回或删除。

卸载扩展会清掉扩展侧的存储；卸载桌面程序**默认保留**上面那个档案目录，要删得在卸载器里单独确认一次。

## 会发到外面的东西

以下 AI 功能会把用户内容发到你自行配置的接口，均由你主动触发：

1. **扩展的「AI 填写」及「AI 辅助新增条目」**：扩展把当前表单的字段说明和相关的简历片段交给本机的桌面程序，由桌面发给你在桌面设置里选为「当前使用」的 OpenAI 兼容接口；辅助新增条目时会发送页面中候选新增按钮的说明及条目数量，以生成供你预览的新增方案。密码、验证码类字段不会发送。
2. **桌面的「AI 解析简历」**：在桌面「简历」页选择 PDF、DOCX 或 TXT 简历并确认后，桌面先在本机提取文字，再把整份简历文字发送到你配置的 AI 接口，以生成结构化模板。这些文字可能包含姓名、联系方式、教育和工作经历等信息；原始文件本身不会随这个请求上传。发送前会显示发往哪个服务商和字数。
3. **桌面的「AI 整理」**：把你导入的那封通知的正文，和最多 8 条候选申请的**公司名、岗位名、当前阶段**，发给你在桌面设置里填的那个接口。发送前会把要发的内容摆给你看，点了「发送」才发。

这些功能都有同一件事要说清楚：**接口是你自己配的，数据会到那家服务商手里，他们可能留存。** 我们既不代理、也看不到这些请求。请求使用你配置的 API Key 向该接口认证。不配置 AI 时，仍可导入 Excel 模板、手动填写和使用本地岗位管理；AI 填写、AI 简历解析和 AI 整理不可用。

桌面程序还会在你允许的情况下去 GitHub 查一次「有没有新版本」。这个请求不带账号标识，但和任何网络请求一样会让服务器看到常规的 IP / User-Agent 元数据；它只查版本，可以在设置里关掉。

除你主动触发的 AI 功能所需的请求外，扩展不会把页面内容、填写内容或浏览记录发给第三方。

## 不会发生的事

- 不上传你的简历、申请记录、附件到我们这里——我们没有「这里」。
- 不做用户画像、不做行为分析、不埋点、不接广告或第三方统计。
- 内容脚本会在所有网站注入，用来在本地判断当前页是不是网申表单；判断只在你的浏览器里做，不上传页面内容。只有你主动使用填写功能时，才会读写当前页的表单字段。
- 扩展用 `tabs` 识别当前标签页，并向该页的内容脚本发送用户触发的填表操作；也会查询扩展自己的状态页 URL 以复用已打开的标签页。不会采集浏览历史。
- 扩展不持有 AI Key，也不直接连接任何 AI 服务商；桌面程序不会把 Key 回传给扩展。唯一的例外是上面说的一次性旧数据迁移：旧 Key 从扩展交给桌面，存进系统凭据库。

## 权限为什么要这些

| 权限 | 用来做什么 |
| --- | --- |
| `<all_urls>` 的 host 权限与内容脚本 | 网申页面遍布各家公司自己的域名，事先列不出来。内容脚本会在所有网站注入并在本地判断当前页是否为表单；只有你主动使用填写功能时才读写当前页字段 |
| `tabs` | 识别当前标签页，并查找、复用本扩展状态页；侧栏通过扩展消息向当前页内容脚本发送用户触发的填表操作，不采集浏览历史 |
| `sidePanel` | 在 Chrome / Edge 浏览器边缘显示填表助手；侧栏通过扩展消息与当前网页的内容脚本协作 |
| `storage` | 存侧栏界面状态、与桌面的待同步队列和旧数据迁移状态 |
| `nativeMessaging` | 和桌面程序通信：读取简历、写回「我的信息」、转发 AI 请求、保存岗位与投递记录。host 清单里只写了本扩展的 ID，别的扩展启动不了它 |
| `offscreen` | 在离屏文档中运行随包提供的 Worker，组装用户主动触发的 AI 填写与 AI 辅助新增条目的提示词并校验结果；请求本身交给桌面程序发出 |
| `alarms` | 安排与桌面程序离线补传、旧数据迁移状态查询的重试 |

## 联系方式

有问题或要求删除什么，可以在
[GitHub Issues](https://github.com/TshyGO/resume-form-assistant-plugin/issues) 上提。
不过说明白一点：**我们手里没有你的数据可删**——所有东西都在你自己的电脑上，删除它就是删你本机的文件。
