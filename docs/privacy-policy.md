# Resume Pro 隐私政策

最后更新：2026-09-17

Resume Pro 是一个求职网申的填写辅助工具，由浏览器扩展和桌面程序两部分组成。
这份政策说明它**收集什么、不收集什么、数据去了哪里**。

## 一句话

**我们没有服务器，也不接收你的任何数据。** 简历、申请记录、附件全部留在你自己的电脑上；
只有你主动使用 AI 功能时，相关内容才会发给**你自己配置的**那家 AI 服务商。

## 数据存在哪

| 数据 | 位置 |
| --- | --- |
| 简历模板、字段设置、AI 配置（扩展侧） | 浏览器的 `chrome.storage.local`，只在这台机器上 |
| 申请记录、回复证据、附件、待办、备份（桌面侧） | Windows `%LOCALAPPDATA%\ResumePro`，macOS `~/Library/Application Support/ResumePro` |
| 桌面的 AI API Key | Windows 凭据管理器 / macOS 钥匙串。不进档案、不进备份、不进日志 |

卸载扩展会清掉扩展侧的存储；卸载桌面程序**默认保留**上面那个档案目录，要删得在卸载器里单独确认一次。

## 会发到外面的东西

只有两种情况，而且都要你主动触发：

1. **扩展的「AI 填写」**：把当前表单的字段说明和相关的简历片段，发给你在设置里填的那个 OpenAI 兼容接口。
2. **桌面的「AI 整理」**：把你导入的那封通知的正文，和最多 8 条候选申请的**公司名、岗位名、当前阶段**，发给你在桌面设置里填的那个接口。发送前会把要发的内容摆给你看，点了「发送」才发。

这两条都有同一件事要说清楚：**接口是你自己配的，数据会到那家服务商手里，他们可能留存。** 我们既不代理、也看不到这些请求。不配 AI 的话，整个产品照常用，只是没有自动填写和自动整理。

桌面程序还会在你允许的情况下去 GitHub 查一次「有没有新版本」。那是一个不带任何身份信息的公开请求，可以在设置里关掉。

## 不会发生的事

- 不上传你的简历、申请记录、附件到我们这里——我们没有「这里」。
- 不做用户画像、不做行为分析、不埋点、不接广告或第三方统计。
- 不读你浏览器里别的标签页；扩展只在你打开的网申页面上工作。
- 不把浏览器扩展里的 AI Key 复制给桌面程序，反之亦然。两边是两条独立的凭据。

## 权限为什么要这些

| 权限 | 用来做什么 |
| --- | --- |
| `<all_urls>` 的 host 权限与内容脚本 | 网申页面遍布各家公司自己的域名，事先列不出来。只有你在某个页面上使用填写功能时才真的读写那一页 |
| `tabs` | 在多标签页之间把「刚才那一页的岗位」对上；需要读标签页的 URL 和标题 |
| `scripting` / `activeTab` | 按你的点击把填写逻辑注入当前页面 |
| `storage` | 存简历模板和设置 |
| `nativeMessaging` | 和桌面程序通信。host 清单里只写了本扩展的 ID，别的扩展启动不了它 |
| `offscreen` / `alarms` | 解析简历文件、安排离线补传的重试 |

## 联系方式

有问题或要求删除什么，可以在
[GitHub Issues](https://github.com/TshyGO/resume-form-assistant-plugin/issues) 上提。
不过说明白一点：**我们手里没有你的数据可删**——所有东西都在你自己的电脑上，删除它就是删你本机的文件。
