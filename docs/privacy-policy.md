# 网申快填隐私政策

最后更新：2026-10-03（可选匿名错误报告和手动反馈，随包含该功能的版本生效）

网申快填是一个求职网申的填写辅助工具，由浏览器扩展和桌面程序两部分组成。
这份政策说明它**收集什么、不收集什么、数据去了哪里**。

## 一句话

简历、申请记录、附件保存在你自己的电脑上。主动使用 AI 时，相关内容发给**你自己配置的**服务商。
匿名错误报告默认开启，也可以预览后手动反馈问题；脱敏报告发到我们的 Cloudflare 中转，再由 Muse 脱敏整理为 GitHub issue。

## 数据存在哪

| 数据 | 位置 |
| --- | --- |
| 简历模板、「我的信息」、申请记录、回复证据、附件、待办、备份 | 桌面程序档案：Windows `%LOCALAPPDATA%\ResumePro`，macOS `~/Library/Application Support/ResumePro` |
| AI 服务商设置（地址、模型） | 桌面程序档案目录下的设置文件，不含 Key |
| AI API Key | Windows 凭据管理器 / macOS 钥匙串。不进档案、不进备份、不进日志 |
| 扩展侧 | 浏览器的 `chrome.storage.local`：侧栏界面状态、与桌面的待同步队列、最近 200 次已处理填写的去重 ID 和结果、旧数据迁移状态。去重记录不含网页填写值。迁移完成后不存简历、不存 Key；只有没能迁过去的部分（见下段）暂留，直到你取回或删除 |

从 0.4.0 升级时，扩展里旧版留下的模板、「我的信息」和 AI 配置（含 Key）会在你于桌面确认后迁入桌面，随后从扩展里删除；迁移只经本机 Native Messaging，不经过网络。没能迁移的部分（桌面拒收的模板、桌面没导入的 Key）留在扩展里，你可以在扩展状态页取回或删除。

卸载扩展会清掉扩展侧的存储；卸载桌面程序**默认保留**上面那个档案目录，要删得在卸载器里单独确认一次。

## 会发到外面的东西

以下 AI 功能会把用户内容发到你自行配置的接口，均由你主动触发：

1. **扩展的「AI 填写」及「AI 辅助新增条目」**：扩展把当前表单的字段说明和相关的简历片段交给本机的桌面程序，由桌面发给你在桌面设置里选为「当前使用」的 OpenAI 兼容接口；辅助新增条目时会发送页面中候选新增按钮的说明及条目数量，以生成供你预览的新增方案。密码、验证码类字段不会发送。
2. **扩展的「保存岗位到桌面端」**：本地认不全公司或岗位时，扩展把页面上几段相关文字（公司名称、职位标题、页面标题这类，最多 8 段，每段不超过 160 字）交给桌面程序，由桌面发给你选为「当前使用」的接口识别。不发送整页、表单里填的内容、简历或网页链接。识别出的结果要你在表单里确认后才保存。
3. **桌面的「AI 解析简历」**：在桌面「简历」页选择 PDF、DOCX 或 TXT 简历并确认后，桌面先在本机提取文字，再把整份简历文字发送到你配置的 AI 接口，以生成结构化模板。这些文字可能包含姓名、联系方式、教育和工作经历等信息；原始文件本身不会随这个请求上传。发送前会显示发往哪个服务商和字数。
4. **桌面的「AI 整理」**：把你导入的那封通知的正文，和最多 8 条候选申请的**公司名、岗位名、当前阶段**，发给你在桌面设置里填的那个接口。发送前会把要发的内容摆给你看，点了「发送」才发。

这些功能都有同一件事要说清楚：**接口是你自己配的，数据会到那家服务商手里，他们可能留存。** 我们既不代理、也看不到这些请求。请求使用你配置的 API Key 向该接口认证。不配置 AI 时，仍可导入 Excel 模板、手动填写和使用本地岗位管理；AI 填写、保存岗位时的识别、AI 简历解析和 AI 整理不可用。

桌面程序还会在你允许的情况下去 GitHub 查一次「有没有新版本」。这个请求不带账号标识，但和任何网络请求一样会让服务器看到常规的 IP / User-Agent 元数据；它只查版本，可以在设置里关掉。

## 匿名错误报告与手动反馈

自动报告默认开启，用于定位错误、改进填写兼容性。插件首次打开侧栏或状态页时显示说明公告，列明内容、用途和关闭入口，提供“知道了”，侧栏公告另提供“关闭自动错误报告”；说明可在插件状态页的“自动错误报告”框内通过“查看完整说明”重看。桌面首次打开界面时也显示说明公告，提供“知道了 / 关闭自动上报”；可随时在桌面“设置 → 隐私”调整。两端的“知道了”只收起公告，上报不以确认公告为前提。插件可在状态页取消勾选“开启自动错误报告”关闭；关闭任一端的自动报告会删除该端的随机安装标识，不影响正常使用。升级保留此前明确开启或关闭的选择，尚未选择的安装采用默认开启并显示公告。设置读取或初始化保存失败时不自动发送。插件与桌面分别设置，不同步。

桌面通过本机 Rust 进程发送，捕获 webview、React 界面异常和 Rust panic；panic 上报尽力完成，进程直接终止时无法保证送达。

自动代码异常报告只含错误类别、筛选后的本程序代码位置、版本与系统，不发送任意异常原文（原文可能含用户内容）。网页内容脚本仅报告堆栈属于本扩展的错误，并附出错页 hostname，不含路径、参数、浏览记录；网站自身异常不上报。

普通一键填写扫描到 0 个字段、有匹配字段没填上或提示“先点编辑”时，附上填写诊断：计数、耗时、错误类别、域名、控件结构和进一步筛选的字段名。取消、拒绝覆盖、辅助新增和全部填上不触发。禁止发送简历、字段值、页面正文、完整网址、Cookie、API Key、AI 请求或响应正文。

不启用自动报告也能“手动反馈问题”。描述先清洗邮箱、电话、长数字串、网址、凭据和用户目录，诊断默认勾选且可取消。发送前完整预览实际报告。自动规则无法判断任意自然语言是否含私人信息，请勿在描述中填写姓名、简历、账号或密钥，核对后再确认发送。

同一错误或同一网站同类填写失败 24 小时最多自动发送一次，合计每小时最多 5 条；429/5xx 后暂停自动发送一小时。请求 5 秒超时，不做离线队列或自动重试；失败的自动发送也占用当日该错误的去重名额。手动反馈至少间隔 60 秒，明确显示成功或失败。

报告发往 `https://app-feedback-relay.nebula-lab.workers.dev/feedback`。错误报告会暂存在我们的数据中转服务中，最长保留 90 天，到期自动删除；上报的 IP 地址仅用于防滥用，不会出现在公开的 issue 中。Muse 整理后的报告可能公开出现在本项目 GitHub Issues，网站域名会保留用于复现。

本机保存开关与公告确认状态、随机标识、节流时间和错误特征哈希，不持久化自动报告正文。自动报告的安装标识仅开启后生成；手动报告使用每次新生成的随机标识，不要求开启自动上报。

## 不会发生的事

- 不向反馈中转上传你的简历、申请记录或附件。
- 不做用户画像、不做行为分析、不埋点、不接广告或第三方统计。
- 内容脚本会在所有网站注入，用来在本地判断当前页是不是网申表单；判断只在你的浏览器里做，不上传页面内容。只有你主动使用填写功能时，才会读写当前页的表单字段。
- 扩展用 `tabs` 识别当前标签页，并向该页的内容脚本发送用户触发的填表操作；也会查询扩展自己的状态页 URL 以复用已打开的标签页。不会采集浏览历史。
- 扩展不持有 AI Key，也不直接连接任何 AI 服务商；桌面程序不会把 Key 回传给扩展。唯一的例外是上面说的一次性旧数据迁移：旧 Key 从扩展交给桌面，存进系统凭据库。

## 权限为什么要这些

| 权限 | 用来做什么 |
| --- | --- |
| `<all_urls>` 的 host 权限与内容脚本 | 网申页面遍布各家公司自己的域名，事先列不出来。内容脚本会在所有网站注入并在本地判断当前页是否为表单；只有你主动使用填写功能时才读写当前页字段 |
| `tabs` | 识别当前标签页，并查找、复用本扩展状态页；侧栏通过扩展消息向当前页内容脚本发送用户触发的填表操作，不采集浏览历史 |
| `sidePanel` | 在 Chrome / Edge 浏览器边缘显示填表助手；侧栏通过扩展消息与当前网页的内容脚本协作 |
| `storage` | 存侧栏界面状态、与桌面的待同步队列、填写留档去重记录、旧数据迁移状态，以及反馈开关与公告确认状态、随机标识与节流记录 |
| `nativeMessaging` | 和桌面程序通信：读取简历、写回「我的信息」、转发 AI 请求、保存岗位与投递记录。host 清单里只写了本扩展的 ID，别的扩展启动不了它 |
| `offscreen` | 在离屏文档中运行随包提供的 Worker，组装用户主动触发的 AI 填写、AI 辅助新增条目和保存岗位时识别的提示词并校验结果；请求本身交给桌面程序发出 |
| `alarms` | 安排与桌面程序离线补传、旧数据迁移状态查询的重试 |
