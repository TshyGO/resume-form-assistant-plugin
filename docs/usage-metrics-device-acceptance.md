# 使用统计隔离真机验收（Mac/Windows × Chrome/Edge）

此页是测试步骤，不代表已完成四种组合的验收。源代码来自#267→#268→#270→#272叠加分支；专用验收包另行review，main不改、不合并、不发布正式版本。

## 验收包隔离

专用release feature `usage-metrics-acceptance` 和编译标记一起启用时，固定连接测试Worker，仍要求查看notice v2与主动使用。普通debug/test/CI和未配置的正式构建继续禁发。测试包不能使用正式接收地址，没有任何Token/HMAC密钥。

包标识为`com.resumepro.metrics.acceptance`，窗口标题“网申快填统计测试 — 仅使用虚构数据”。启动时强制隔离数据/缓存：

- Mac：`~/Library/Application Support/ResumeProUsageMetricsTest/usage-metrics-test-data`
- Windows：`%LOCALAPPDATA%\ResumeProUsageMetricsTest\usage-metrics-test-data`

不接受环境变量把测试数据改指向正式档案，检测测试根部符号链接后停启。系统Key服务名、Native Messaging host均独立，后者为`com.resumepro.metrics.test`。原插件、原宿主注册和`ResumePro`档案不覆盖。桌面和测试插件自动错误反馈均禁用。

打包验证二进制`--metrics-test-info`，校验测试身份、固定地址及反馈禁用；receipt记录源SHA、平台、二进制/原插件ZIP的SHA256、已审核的插件临时改动。上传的是ZIP，保留Mac可执行权限；不是安装器，不写正式安装位置。

## 开始之前

1. 使用发给你的对应平台ZIP解压到新文件夹，不覆盖现有程序。
2. 维护者先确认测试云端采集开关已在本次联调窗口开启。否则当天失败会消耗额度，不应先反复点击。
3. Mac 双击“打开测试版.command”（或 Resume Metrics Test.app），Windows 双击“打开测试版.cmd”，确认窗口名称有“统计测试”；错误反馈选“暂不开启”。禁止导入真实简历、档案备份或真实AI Key。
4. 保持测试桌面已打开，再用包中的“打开Chrome测试/打开Edge测试”（Mac 选 .command，Windows 选 .cmd）进入独立浏览器配置；Mac 启动文件会把专用测试宿主配置复制到对应独立浏览器目录，在扩展管理页开启开发者模式并“加载已解压的扩展”，选择包内plugin文件夹。确认名称为“网申快填统计测试”，不要在日常浏览器配置覆盖正式插件。
5. 使用虚构模板和虚构个人信息，例如“测试公司/测试岗位”，不访问真实网申表单；测试插件的状态页/侧栏输入即可验证本机信号。

## 操作与预期

每个平台依次执行，记录北京时间、平台、浏览器、可见结果即可，别复制随机安装编号到聊天。维护者通过不含设备标识的报表和合成样本检查数据。

| 步骤 | 用户操作 | 预期 |
| --- | --- | --- |
| A | 未查看首次说明时操作窗口 | 无统计编号或HTTP活动请求，历史点击不补传 |
| B | 看完说明，保持默认开启，再主动操作桌面 | 一条desktop样本，不影响档案操作 |
| C | Chrome测试侧栏正常连接后主动点击/输入 | 同一安装出现extension来源，不增加第二个安装 |
| D | Edge测试侧栏正常连接后主动点击/输入 | 与Chrome共用extension额度，当日不增加安装 |
| E | 多次点击/输入、隐藏窗口、后台同步 | 当天同来源最多一次；隐藏/后台不新增活动 |
| F | 设置→隐私关闭统计，再操作两个浏览器 | 本机停发，原明细尽力删除；UI区分pending/deleted/unconfirmed |
| G | 退出并重启测试版 | 开关仍关闭，不发送新活动 |
| H | 断网、重新打开后关闭统计 | 正常功能继续，关闭不等待网络，不能假称云端删除成功 |
| I | 手动再开启，在下一次主动使用时测试 | 新编号、不补发关闭期；需考虑插件本机当日尝试门限，重启独立浏览器后再测 |
| J | 桌面完全退出后操作测试插件 | 统计不拉起桌面，不显示统计错误；普通明确业务操作仍按原功能处理 |

Mac+Chrome、Mac+Edge、Windows+Chrome、Windows+Edge均需人工完成并记录。跨午夜与45/365天不等待真实天数，依靠已通过的D1/状态回归；真机重点是窗口可见信号、跨进程/浏览器去重、持久关闭和失败不影响功能。
